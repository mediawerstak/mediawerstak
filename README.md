# MediaWerstak — контент-завод

MediaWerstak производит контент для соцсетей под ключ: 10 тематик, 7 площадок,
ежедневный выход. Это не блог, а производство: контент-план, визуал, тексты,
график публикаций и разметка под поиск.

## Что здесь

- `index.html` — стартовая страница со списком статей.
- `articles/` — опубликованные статьи (HTML, статическая разметка, видна поисковикам).
- `sitemap.xml`, `robots.txt` — карта сайта для Google.

## Темы

Хорошие новости, наука и природа, эстетика, мир, жизненное, факты, бизнес,
здоровье, душевные цитаты, биохакинг.
